# Atividade Portfólio

Você deverá implmentar este projeto utilizando o framework vue.js

## Branch ft-html
Projeto com páginas construídas em HTML e CSS

## Branch ft-vue3-sem-diretiva
Projeto com as páginas componentizadas e com rotas

## Branch ft-vue3-com-diretiva
Projeto com as páginas utilizando as diretivas v-for e v-if para fazer a montagem do conteúdo
